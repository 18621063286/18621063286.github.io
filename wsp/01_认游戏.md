# 第 1 章　从权重认出游戏

> 原实验：`upstream/exp1_which_game/`　|　博客：Experiment 1　|　难度 ★　|　只需 CPU

## 1.1 问题

给你一个用 PPO 训练好的游戏策略网络。只看它的 17,253 个权重，不告诉你是哪个游戏，也不给候选列表，
你能说出它是在玩什么游戏吗？

四个网络的结构完全一样：`500 → 32 → 32 → 5`，激活函数是 tanh。
- **输入**：10×10 网格，每个格子 5 个二值通道（0 agent、1 移动物体、2 奖励目标、3 障碍物、4 上一帧），展平成 500 个数，
  第 i 个输入 = `(row*10 + col)*5 + channel`。
- **输出**：5 个动作的 logits（no-op、up、down、left、right）。

## 1.2 核心原理：梯度只会流到"出现过"的输入

第一层的计算是 `h = tanh(x @ W1 + b1)`，`W1` 第 i 行对应第 i 个输入。对这一行求梯度：

```
∂L/∂W1[i, :] = x_i · δ        （δ 是第一层的反向误差）
```

**如果某个输入 x_i 在整个训练过程中一直是 0，这一行就永远收不到梯度，权重会停留在初始化时的值。**

所以只要比较每一行的大小（L2 范数），就能知道"训练时哪些格子、哪些通道里出现过东西"。这几乎就是在**看这个游戏的地图**。

> **小测验**：这个推理依赖哪些前提？什么情况下会失效？

<details markdown="1"><summary>答案</summary>

1. 没有权重衰减（weight decay），否则没用到的权重会被慢慢压向 0，而不是停在初始化值（不过照样会和训练过的行区分开）。
2. 优化器不会改动梯度为 0 的参数。Adam 在梯度恒为 0 时更新量为 0，满足这个前提。
3. 输入是稀疏的二值量。如果输入是稠密的连续值（比如原始像素），每一行都会收到梯度，这一招就不好用了。
第 3 章的语言模型就是一个反例：输入嵌入层被拿掉了，这个线索也就没有了。

</details>

## 1.6 批判性思考

1. **这个任务比听起来简单。** prompt 里告诉了每个通道的含义（"agent"、"reward targets"），再加上 1.2 节的原理，
   看懂地图并不需要什么"理解网络在计算什么"。你用一个 30 行的脚本就做到了。
2. **Astra 只用了大约 1,000 个推理 token 就答对了**。这说明它可能也在用和你类似的"看哪里的数字大"的捷径。
3. **怎样让任务更难、更能考察真正的理解？**（这正是 `PLAN.md` 里的消融实验 1b）
   - 去掉通道语义，只写"通道 0 到 4"
   - 打乱通道顺序
   - 给网络加上权重衰减后重新训练（让没用到的行不再停在初始化值）
